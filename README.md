# 🎬 Netflix Clone Website

A Netflix-inspired responsive website built using **HTML, CSS, and JavaScript**. This project recreates the Netflix user interface to practice frontend web development and improve UI design skills.

## 🚀 Features

- Netflix-inspired user interface
- Attractive movie and TV show sections
- Custom styling using CSS
- Interactive elements using JavaScript
- Image-based visual content
- Responsive web design (if supported by the implementation)

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Interactive functionality

## 💻 How to Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Open `Netflixclonepro.html` in your browser.
4. Explore the Netflix Clone Website.
